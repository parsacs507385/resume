## ✨ Features

### 🔐 Authentication
- Sign up / Login
- Password recovery
- Gender detection from name (AI-powered, deprecated)

### 👨‍🏫 Mentor Features
- Add students via QR code
- Manage student limits (deprecated)
- Track homework (solved/unsolved)
- Analyze student exam performance (question-by-question)
- View student rankings among their students
- Manage income from students
- Change in-app currency for each student
- Receive withdrawal requests from students
- Send/receive messages to/from students

### 🧑‍🎓 Student Features
- Submit homework with AI-generated questions
- Practice and answer AI-generated questions
- Learn from AI-generated explanations
- View exam performance analysis
- In-app shop
- In-app currency system
- Convert currency to real money
- Chat with mentor
- Upload profile photo (AI-moderated for appropriateness, deprecated)

### 🤖 AI Capabilities
- Homework question generation
- Question-by-question exam analysis
- Gender detection from name (deprecated)
- Profile photo moderation (deprecated)

| **AI/ML** | TensorFlow, Scikit-learn, Transformers |
| **Real-time** | Django Channels / WebSockets (deprecated) |
| **Payments** | Zarinpal / Local payment gateways |
| **Deployment** | Nginx, Gunicorn |
